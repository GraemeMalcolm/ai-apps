Artificial Intelligence (AI) enables machines to simulate human thinking and problem-solving. It is built on machine learning and spans sub-areas such as generative AI, text analysis, speech, computer vision, and information extraction.

CATEGORY: Machine Learning
CATEGORY LEARNING RESOURCE: https://aka.ms/aisn-ml-concepts-mod

TOPIC 3: Introduction to Machine Learning
SEARCH TERMS: machine learning, ml, predictive model, predictive models, predictive modeling, supervised learning, unsupervised learning, features, label
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/12719512-1cb0-430c-b09e-2798d6989012
ANSWER:
Machine Learning is a subset of AI where computers learn from data to make predictions without explicit programming. Models learn from inputs called features to predict outputs called labels. The main approaches are supervised learning (using labeled examples) and unsupervised learning (finding patterns without labels).

------------------------------------------------------------------------

TOPIC 4: Regression
SEARCH TERMS: regression, regressor, regressors, linear regression
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/951d39cc-8866-41ad-8780-819dab65488f
ANSWER:
Regression is a supervised learning technique for predicting continuous numerical values, such as house prices or sales figures. Linear regression assumes a straight-line relationship between inputs and output; more complex techniques capture non-linear patterns.

------------------------------------------------------------------------

TOPIC 5: Classification
SEARCH TERMS: classification, classifier, classifiers, binary classification, multiclass classification, logistic regression
ANSWER:
Classification is a supervised learning technique that assigns items to predefined categories. Binary classification predicts one of two outcomes (e.g. spam or not); multiclass classification predicts one of three or more categories. Models learn from labeled data and calculate the probability for each class.

------------------------------------------------------------------------

TOPIC 6: Clustering
SEARCH TERMS: clustering, cluster, clusters, k-means
ANSWER:
Clustering is an unsupervised learning technique that groups similar items by shared features without labeled data. For example, grouping customers by purchasing behavior. Common algorithms include K-means, used in market research and anomaly detection.

------------------------------------------------------------------------

TOPIC 7: Deep Learning and Neural Networks
SEARCH TERMS: deep learning, neural network, artificial neural network, fully connected network, multi layer perceptron
ANSWER:
Deep learning uses neural networks with many layers to recognize complex patterns. Networks adjust connection strengths during training to minimize errors. It powers image recognition, speech processing, natural language understanding, and large language models.

------------------------------------------------------------------------

CATEGORY: Generative AI and Agents
CATEGORY LEARNING RESOURCE: https://aka.ms/aisn-gen-ai-concepts-mod

TOPIC 8: Introduction to Generative AI
SEARCH TERMS: generative ai, genai, prompt, prompts, prompt engineering
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/904e700e-4549-42ac-8056-7e4dfd505966
ANSWER:
Generative AI models produce new content such as text, images, audio, or video from patterns learned during training. Most are large language models built on transformer architectures. Users provide natural language prompts, and prompt engineering is the practice of crafting effective prompts to guide the output.

------------------------------------------------------------------------

TOPIC 9: Large Language Models
SEARCH TERMS: large language model, large language models, llm, llms, gpt
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/298e27ef-f5b0-4ed7-ade5-623d8465105a
ANSWER:
Large Language Models (LLMs) understand and generate human language at scale using transformer architectures. They break text into tokens, convert them to embeddings, and use attention to understand relationships. LLMs perform tasks like writing, translation, summarization, and question answering without task-specific retraining.

------------------------------------------------------------------------

TOPIC 10: AI Agents
SEARCH TERMS: agents, agent, agentic
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/17ea5149-8d84-4d51-8c46-e1a86d21815f
ANSWER:
AI agents perform tasks on behalf of users. They combine a large language model, behavioral instructions, and tools connected to external systems.

------------------------------------------------------------------------

TOPIC 11: Transformer models and Attention
SEARCH TERMS: transformer, transformers, attention, self-attention, multi-head attention, encoder, decoder, encoder-decoder, embedding, embeddings, vectors, vector, tokens, token
ANSWER:
Transformers underpin most modern AI systems. They map input tokens to embedding vectors and use self-attention to capture relationships between tokens. Encoders process input and decoders generate output; multi-head attention allows the model to consider multiple relationship types at once.

------------------------------------------------------------------------

TOPIC 12: Prompt Engineering
SEARCH TERMS: prompt engineering, prompt, prompts, instruction, instructions, few shot learning, zero shot learning
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/2330092e-48b9-4d41-905b-e1b4fd002356
ANSWER:
Prompt engineering is crafting inputs to guide AI models toward accurate responses. Techniques include clear instructions, context, and worked examples. Few-shot prompting includes examples in the prompt; zero-shot relies on the model's existing knowledge.

------------------------------------------------------------------------

TOPIC 13: Fine-tuning and Custom Models
SEARCH TERMS: fine tuning, fine-tune, custom model, custom models, transfer learning
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/4955a5e7-d701-469a-a845-93bb0b070003
ANSWER:
Fine-tuning adapts a pre-trained AI model to a specific task or domain. It requires far less data than training from scratch and tailors the model to specific terminology or workflows, producing a custom model.

------------------------------------------------------------------------

TOPIC 14: Evaluation of Generative AI Models
SEARCH TERMS: evaluation, evaluate, model evaluation, generative ai evaluation, accuracy, coherence, relevance, diversity
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/e24b97c9-21ac-4465-bf20-ec0a35e55ed7
ANSWER:
Evaluating generative AI ensures outputs meet quality standards. Key dimensions are accuracy (match to expected results), coherence (logical flow), relevance (addresses the prompt), and diversity (variety of outputs). Evaluation combines automated scoring with human review.

------------------------------------------------------------------------

TOPIC 15: Retrieval-Augmented Generation (RAG)
SEARCH TERMS: retrieval augmented generation, rag, knowledge retrieval, external knowledge, contextual information
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/1101153e-8d13-4c60-bf09-d44eafc02c27
ANSWER:
Retrieval-Augmented Generation combines a generative AI model with external knowledge retrieval. Relevant documents are retrieved at query time and added to the prompt. This improves accuracy when answers depend on current or domain-specific information.

------------------------------------------------------------------------

TOPIC 16: Tools and Skills
SEARCH TERMS: tools, tool, skills, skill
ANSWER:
AI agents use tools and skills to extend their capabilities. Tools are external connections to systems and data sources; skills are instructions that guide the agent on how to use those tools to achieve specific goals.

------------------------------------------------------------------------

TOPIC 17: Model Context Protocol (MCP)
SEARCH TERMS: model context protocol, mcp
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/6285aa6e-5787-4375-914a-ab4e1f54a400

The Model Context Protocol (MCP) is a standard interface allowing AI agents to discover and connect to external tools without custom integration code. Agents that support MCP can automatically use any compatible tool, making it easier to build agents that take real-world actions.

CATEGORY: Text Analysis
CATEGORY LEARNING RESOURCE: https://aka.ms/aisn-nlp-concepts-mod

TOPIC 18: Common Text Analysis Techniques
SEARCH TERMS: text analysis, text analytics, analyze text, term frequency, tf-idf, tfidf, stemming, lemmatization, parts of speech, pos tagging, tokenization
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/0ce04283-6436-44f0-9838-1a9b293e5ed1
ANSWER:
Text analysis extracts meaning from text. Term Frequency counts word occurrences; TF-IDF also weighs word rarity to highlight distinctive terms. Stemming and lemmatization reduce words to their root form, and parts-of-speech tagging labels each word by grammatical type.

------------------------------------------------------------------------

TOPIC 19: Natural Language Processing
SEARCH TERMS: natural language processing, nlp
ANSWER:
Natural Language Processing (NLP) enables machines to understand and generate human language. It includes large language models and is applied in keyword extraction, sentiment analysis, and summarization.

------------------------------------------------------------------------

TOPIC 20: Text Summarization
SEARCH TERMS: text summarization, summarization, extractive summarization, abstractive summarization, textrank, summary
ANSWER:
Text summarization generates a concise summary of a longer document. Extractive summarization selects key sentences unchanged, using algorithms like TextRank to rank them. Abstractive summarization, powered by large language models, generates new paraphrased sentences.

------------------------------------------------------------------------

TOPIC 21: Key Term Extraction
SEARCH TERMS: key term extraction, key phrase extraction, keyword extraction, term extraction, important terms
ANSWER:
Key term extraction identifies the most important words and phrases in a document, surfacing main topics for indexing, search, and categorization. Common approaches combine TF-IDF with noun phrase detection.

------------------------------------------------------------------------

TOPIC 22: Text Classification
SEARCH TERMS: text classification, classify text, text categorization, sentiment analysis, sentiment, analyze sentiment, predict sentiment, opinion mining, document classification
ANSWER:
Text classification assigns labels to documents using supervised learning, with applications like spam detection and topic categorization. Sentiment analysis identifies whether text expresses a positive, negative, or neutral opinion.

------------------------------------------------------------------------

CATEGORY: Speech
CATEGORY LEARNING RESOURCE: https://aka.ms/aisn-speech-concepts-mod

TOPIC 23: Overview of Speech
SEARCH TERMS: speech, voice, audio, speak, speaking, talk, talking
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/882f1af7-944c-4be0-97c3-889dd985df68
ANSWER:
Speech technologies enable computers to understand and generate human speech. The two main tasks are Speech Recognition (speech to text) and Speech Synthesis (text to speech). Use cases include voice assistants like Microsoft Copilot, transcription services, accessibility tools, and language translation.

------------------------------------------------------------------------

TOPIC 24: Speech Recognition (Speech to Text)
SEARCH TERMS: speech to text, speech-to-text, speech recognition, stt, mfcc, mfccs, mel frequency cepstral coefficients, phoneme, phonemes, acoustic model, language model, word prediction
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/cb7fbb9d-e62b-455e-9fa6-b6ac79ed3cf1
ANSWER:
Speech recognition converts spoken language to written text. An acoustic model identifies phonemes from audio; a language model predicts the most likely word sequence. Modern systems use deep learning for high accuracy across speakers, accents, and recording conditions.

------------------------------------------------------------------------

TOPIC 25: Speech Synthesis (Text to Speech)
SEARCH TERMS: tts, text to speech, text-to-speech, speech synthesis, voice generation, grapheme, graphemes, prosody, intonation, pitch, vocoder
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/a83e3e97-a8ad-4368-9fa1-b7aef21f4e7c
ANSWER:
Speech synthesis (text-to-speech) converts written text into spoken audio. It maps characters to speech sounds and applies prosody rules for natural rhythm, pitch, and emphasis. A neural vocoder generates the final audio waveform, and modern systems use deep learning to produce natural-sounding voices.

------------------------------------------------------------------------

CATEGORY: Computer Vision
CATEGORY LEARNING RESOURCE: https://aka.ms/aisn-vision-concepts-mod

TOPIC 26: Computer Vision Overview
SEARCH TERMS: computer vision, vision, image classification, object detection, semantic segmentation, visual recognition, image analysis, photo, photograph, picture, camera
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/4258ffd7-61d5-4cc2-992b-7cf059a32c0a
ANSWER:
Computer vision enables computers to interpret images and videos. Common tasks include image classification, object detection, and semantic segmentation. Main model types are CNNs and vision transformers, applied in autonomous vehicles, medical imaging, and facial recognition.

------------------------------------------------------------------------

TOPIC 27: Image Processing
SEARCH TERMS: image processing, pixel, pixels, resolution, filter, filters, convolution, edge detection
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/a2224506-2db8-4fbe-b1c9-1af29fc7b16d
ANSWER:
Image processing analyzes and manipulates digital images made of pixels. Filters detect features or reduce noise â€” edge detection highlights boundaries, blur filters smooth images. Convolution slides a small kernel matrix across the image to produce a transformed output.

------------------------------------------------------------------------

TOPIC 28: Convolutional Neural Networks
SEARCH TERMS: convolutional neural network, convolutional neural networks, cnn, cnns, feature extraction layers, pooling layers, fully connected layers, kernel
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/2fae02ed-55bc-44df-b37f-f7ce2373fe73
ANSWER:
Convolutional Neural Networks (CNNs) are deep learning models for image processing. Convolutional layers detect edges and shapes, pooling layers reduce spatial dimensions, and fully connected layers make final predictions such as image classification.

------------------------------------------------------------------------

TOPIC 29: Vision Transformers
SEARCH TERMS: visual transformer, visual transformers, vision transformer, vision transformers, image transformer, image transformers, vit, vits, multimodal models, patch, patches, crossmodel attention, shared vector space, image captioning
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/9157a9d9-290b-4a2a-99c4-a28eab3369ad
ANSWER:
Vision Transformers apply the transformer architecture to images for tasks like classification and captioning. Images are split into fixed-size patches, each converted to an embedding vector, with self-attention capturing relationships across patches. Multimodal models extend this by sharing an embedding space between images and text.

------------------------------------------------------------------------

TOPIC 30: Image Generation
SEARCH TERMS: image generation, diffusion, diffusion model, video generation, generative model, denoising, image creation, text to image, text-to-image, video creation, dalle, dall-e, sora, mai-image, maiimage
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/5fcc62e3-0757-4eea-a995-c57b3f89ea3b
ANSWER:
Image generation uses AI to create images from text prompts. Diffusion models progressively refine random noise into a coherent image. This powers systems like DALL-E and Stable Diffusion, and has been extended to video generation.

CATEGORY: Information Extraction
CATEGORY LEARNING RESOURCE: https://aka.ms/aisn-info-extract-concepts-mod

SEARCH TERMS: information extraction, document processing, document intelligence, content understanding, document, documents, forms, invoice processing, receipt processing, form processing
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/a9cbad65-a964-47fe-8bfc-fcb12257fd29

Information extraction pulls structured data from unstructured documents. The workflow uses OCR to read text, field extraction to identify data points, and normalization into a consistent format. It automates document-heavy workflows in finance, healthcare, and legal services.

TOPIC 32: Optical Character Recognition (OCR)
SEARCH TERMS: optical character recognition, ocr, text detection, text extraction, character recognition, text region
VIDEO RESOURCE: https://share.synthesia.io/embeds/videos/1c411668-84d6-494f-9d17-1090705e549f
ANSWER:
Optical character recognition (OCR) identifies text in images. It converts images into digital text by detecting text regions and recognizing characters. Modern OCR uses deep learning to handle handwritten text, low-quality scans, skewed pages, and complex layouts. It is foundational for digitizing printed documents.

Field extraction identifies specific data values in documents. Field mapping links extracted values to target database fields. Normalization converts values to consistent formats for use in downstream systems.
