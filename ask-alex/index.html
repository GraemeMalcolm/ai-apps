🎓 About Ask Alex

Ask Alex is a sample AI agent for educational purposes. It is not a supported Microsoft product or service, and is provided as-is with no warranty of any kind.

📋 Important details and AI transparency notes (opens in new window)

Features

  • Multiple Response Modes: AI model mode (Microsoft Phi-4-mini running in WebAssembly), and Basic mode (knowledge-base content without model inference)
  • Grounded Responses: Answers are based on a curated knowledge base about Azure Databricks
  • Search Integration: Seamlessly search Microsoft Learn documentation for Azure Databricks topics
  • Voice Input: Intelligent speech recognition - uses browser's Web Speech API for best results, with automatic fallback to offline Vosk if unavailable

How It Works

Ask Alex runs an AI model in your browser. The initial download may take a few minutes, but once loaded, the model will run locally on your device. The model generates responses to questions about Azure Databricks, and can also use the Microsoft Learn MCP tool to provide links to related documentation.

Getting Started

Try asking a question like "What is Azure Databricks?" or "Explain Apache Spark" to get started.

🤖 About Response Modes

AI model mode uses WebAssembly with the Phi-4-mini model running directly in your browser. No data is uploaded to Microsoft's servers.

Setting the model to None skips model inference entirely and returns matching content directly from the built-in knowledge base.

If the AI model cannot be loaded, the app automatically switches to Basic mode (None) so you can still search the built-in knowledge base content and Microsoft Learn documentation.
